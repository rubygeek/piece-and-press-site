# Piece & Press

Sewing pattern business website. Built with plain HTML/CSS.

## Local preview
Open `index.html` in a browser. No server needed.

## Deploy to Netlify
1. Push this repo to GitHub
2. Go to app.netlify.com → "Add new site" → "Import an existing project"
3. Connect your GitHub repo
4. Netlify auto-detects the build settings from `netlify.toml`
5. Deploy!

## Tech
- Pure HTML + CSS (no framework)
- Deployable anywhere — GitHub Pages, Netlify, Vercel
